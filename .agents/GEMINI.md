# QUY TẮC BẮT BUỘC CHO TRỢ LÝ (ANTIGRAVITY / GEMINI)

## Tự Động Commit & Push Lên GitHub Không Cần Người Dùng Nhập
Mỗi khi trợ lý hoàn thành bất kỳ chỉnh sửa code, tính năng mới, tạo asset hoặc sửa lỗi (bug fix) trong dự án này:
1. **BẮT BUỘC tự động chạy lệnh:**
   ```powershell
   git add . ; git commit -m "<mô tả thay đổi>" ; git push origin main
   ```
   thông qua công cụ `run_command` ngay trong phiên làm việc.
2. **TUYỆT ĐỐI KHÔNG:**
   - Yêu cầu người dùng phải tự gõ lệnh git add / git commit / git push thủ công.
   - Quên đẩy code lên sau khi kết thúc phản hồi.
3. **Báo cáo kết quả:**
   - Trong câu trả lời, chỉ cần thông báo ngắn gọn mã hash commit và xác nhận code đã được tự động đẩy lên GitHub.
